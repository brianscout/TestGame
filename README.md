# Endless Stack

A one-button HTML5 timing game. A block slides back and forth above the tower; drop it to stack it. Any overhang is sliced off, so the tower narrows as you miss. Miss entirely and the game ends.

## Play

Open `index.html` in a browser. No build step, no dependencies.

- **Click / tap / Space / Enter** — drop the block
- **M** — toggle sound

## Rules

- Land within a few pixels of the block below for a **Perfect** — no trim.
- Three or more Perfects in a row grow the block back toward full width.
- Blocks speed up as the tower grows.
- Best score is saved in the browser.
